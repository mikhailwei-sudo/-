# Great Tea Road — бесплатный аудиогид

**Работает сейчас:** `audio-guide.js` читает 8 подготовленных рассказов на русском, китайском и английском. Он выбирает подходящие голоса устройства (или позволяет выбрать вручную), регулирует темп и громкость, разбивает речь на фразы с короткими паузами. Автоматическая экскурсия переходит к следующему экспонату по окончании озвучки.

**Не требует** аккаунтов, API-ключей, подписки или передачи текста через наш сервер. Примечание: некоторые системные голоса браузера работают через облачный сервис своего поставщика.

## Более естественный нейронный голос — бесплатно

Piper TTS позволяет сгенерировать озвучку заранее на своём компьютере. Для веб-сайта удобнее загружать **уже готовые файлы MP3**, а не скачивать тяжёлые голосовые модели на каждый телефон. Это обычно надёжнее для посетителей.

1. Установи Piper TTS и скачай подходящие `.onnx` + `.onnx.json` голосовые модели для **ru_RU / zh_CN / en_US**. Просмотри `MODEL_CARD` каждого выбранного голоса: лицензии у моделей отличаются.
2. При наличии `ffmpeg` генератор создаёт небольшие MP3; иначе создаёт WAV.
3. Выполни из папки `v4`:

```bash
python tools/generate_audio.py --voices \
  ru=voices/ru_RU-irina-medium.onnx \
  zh=voices/zh_CN-huayan-medium.onnx \
  en=voices/en_US-lessac-medium.onnx
```

4. Опубликуй папку `v4/audio/` и обновлённый `audio-guide-manifest.json`. Аудиогид **автоматически предпочтет** нейронные записи для языков/экспонатов из manifest. Если записи нет, используется системный голос.

Для голосов см. https://huggingface.co/rhasspy/piper-voices и https://github.com/OHF-Voice/piper1-gpl

## Историческая достоверность

Рассказы — популярное введение в историю чайного пути, а не идентификация конкретных музейных предметов. Модели и художественные реконструкции различаются в тексте.

## Технические файлы
- `audio-guide-scripts.json` — тексты 8 экспонатов × 3 языка;
- `audio-guide.js` — браузерное воспроизведение, выбор голоса и скорости;
- `audio-guide-manifest.json` — список доступных готовых записей (пока пуст);
- `tools/generate_audio.py` — локальный нейронный генератор для будущих MP3/WAV.
