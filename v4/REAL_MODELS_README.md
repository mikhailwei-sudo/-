# Great Tea Road 4.1 — реальные модели

Встроены присланные пользователем файлы:

- `assets/models/camel-authentic.glb` — 3D-верблюд (3.8 МБ), зал караванов (номер 2);
- `assets/models/samovar-authentic.glb` — 3D-самовар (18 МБ), зал русского чаепития (номер 4).

Временные схематические фигуры убраны из этих двух витрин. Обе модели загружаются только при посещении соответствующего зала, при этом исходные текстуры и материалы GLB сохраняются. Масштаб задаётся по трём осям и проверяется после загрузки.

Лицензию и авторство импортированных моделей необходимо указать по оригинальным страницам, откуда были скачаны GLB (если они предоставлены под CC BY, публичная атрибуция обязательна). Сами файлы предоставлены пользователем.

Для локального запуска: `python -m http.server 8000`, затем `http://localhost:8000/experience.html`. При двойном клике по HTML загрузка GLB может блокироваться браузером.

До публикации важно проверить мобильную производительность (особенно самовар), реальную ориентацию и историческую атрибуцию моделей; тест браузерной отрисовки в данном окружении не подтвержден.
