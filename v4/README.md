# Great Tea Road 4.0 — Chinese entrance hall

Launch with an HTTP server from this folder, e.g. `python -m http.server 8000`, then open `http://localhost:8000/experience.html`.

The entrance hall uses the supplied `chinese-hall.zip` FBX asset. Gallery 1 includes the supplied tea-set GLB; gallery 2 uses the supplied Collada wooden crate. Other artifacts remain procedural. Fallback display persists when models cannot load.

Features: trilingual RU/ZH/EN, four gallery wings, lobby button, smooth camera transitions, object selection, audio guide, and mobile touch controls.
