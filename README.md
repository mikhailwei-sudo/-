# Great Tea Road 2.0 · Великий чайный путь · 万里茶道

Trilingual educational website on the historical tea trade between China, Mongolia and Russia.

## Pages

The static site is ready for GitHub Pages (root `index.html` and `.nojekyll`).

**One-time repository owner action:** open [Settings → Pages](https://github.com/mikhailwei-sudo/-/settings/pages), select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.

Once GitHub Pages deploys successfully, the expected website address is:

https://mikhailwei-sudo.github.io/-/

The [interactive 3D hall](museum.html) is also accessible at `/museum.html`. Three.js is loaded from a public CDN, so WebGL requires an internet connection.

## What is built

- `index.html`: trilingual homepage
- `museum.html`: four exhibit stations and source-linked descriptions
- `museum3d.js`: genuine WebGL / Three.js interactive schematic exhibition hall
- `docs/PROJECT_PLAN.md`: development roadmap
- `docs/PHOTO_SOURCES.md`: curatorial source inventory

**Note:** Current exhibits are schematic procedural models, not scans of real artifacts. Historic museum photos from an earlier local prototype have not been uploaded because provenance and reproduction rights must be checked.
