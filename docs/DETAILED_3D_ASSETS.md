# Museum assets and sources — publication review

**Status:** The repository contains original procedural 3D models, not copyrighted museum image copies.

The earlier local ZIP contains ten historical images. Their exact image rights and attribution need individual verification before publication to this public repository. Museum photos in the collection cards are linked to their source publishers; failed image loads use a textual placeholder, rather than a different photo pretending to be that object.

## Research sources
- Kyakhta museum exhibition: https://ar.culture.ru/tt/exhibition/rossii-chaynoy----staraya-stolica
- Kyakhta photo collection: https://commons.wikimedia.org/wiki/Category:Kyakhta
- Smithsonian tea brick: https://www.si.edu/object/tea-brick-china-19th-century%3Anmah_1068779
- Science Museum compressed tea: https://collection.sciencemuseumgroup.org.uk/objects/co124194/slab-of-compressed-tea-china-before-1930
- Other museum image source links are provided in each gallery card.

**Curatorial accuracy:** The 3D artifacts are unique, interpretive, stylized reconstructions informed by reference material. They are *not* digitized physical artifacts or exact period copies.
