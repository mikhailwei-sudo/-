# Curatorial image and rights checklist

Before publishing a museum image, record:
- exhibit name and original creator / institution
- original URL
- creation date / medium (archival photo, modern museum photo, engraving, replica)
- copyright owner and explicit license/reuse permission
- suitable alt text and attribution text
- last date the reference was checked
