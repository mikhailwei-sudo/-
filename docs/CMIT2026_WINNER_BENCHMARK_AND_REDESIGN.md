# 万里茶道 / Great Tea Road — CMIT 2026 设计升级基准方案

更新日期：2026-11-02

## 核心原则：专业网站 + 萌系角色
网站本体采用可信赖的数字博物馆设计，尼克与茶儿只出现在导览、游戏、语言学习、完成反馈等需要亲和力的场景。禁止直接复制获奖作品的插画、界面或源代码。

## 网站当前问题（基于 2026-11-02 GitHub Chromium 本地运行截图）
- 首页：视觉基调专业，但部分模块强调大面积标题，缺少统一“开始探索”的清晰入口；默认 RU 的历史页面不利于中文答辩。
- 3D 展馆：空间几何与材质仍显示意性；展品、来源与说明可以明显强化；应保留可用的语言/音频选择。
- 三关游戏：视觉与网站主界面差异较大，功能已具雏形；加载与开场之后的引导仍需优化。
- 词典：卡片有实用价值，但多语状态存在混合语言，需要贯通 i18n 验收。

## 新版统一视觉规范（建议）
- 背景：深墨绿 #0E2422；二级容器 #183630；重点文字奶油白 #F6F0E5；细节金 #D6B57D。
- 字体：思源黑体或 Noto Sans CJK SC，历史篇章可用思源宋体；禁用小于 14px 的正文。
- 布局：1200px 主要内容宽度、24px 桌面间距、16px 移动间距。
- 图片：所有历史照片采用固定展示容器，object-fit: contain 不裁切文物，必要时用留白；图片来源可展开。
- 按钮：明确主次、可键盘访问，触控目标 >= 44px，减少视觉噪声。
- 动效：200–300ms、单一层次轻缓过渡，尊重 prefers-reduced-motion。
- 导航：固定“地图 / 数字展馆 / 游戏 / 词典”一级入口，不在各页使用不同别名。

## 角色规范
- 尼克：保留北方服饰、茶叶与商旅物件，头身比约 1:2.5–3.0；茶儿保留中国茶元素与识别配色。
- 作为辅助：欢迎、展品说明、完成关卡、词卡提示；不要在历史照片上遮挡器物正文。
- 角色贴图无裁切、PNG/WebP 透明背景；复用现有 atlas、动作表，不临时混入不一致的概念画。

## 强化跨文化交际（国际专项赛答辩重点）
- 将文物卡片做成文化对照：茶砖（生产/贸易）→ 商队（运输/翻译/接触）→ 萨莫瓦（消费/本地化）。
- 同一展品按语言分别提供可理解的叙事，而不是逐字硬译；清楚标注历史事实/艺术复原/推测。
- “文化对话”微交互：给同一问题展示中俄不同饮茶习惯与共同点，要求用户选择并得到带来源的解释。
- 三语语音独立控制；切换语言不能丢失用户所在位置、游戏进度或正在查看的展品。

## 优先级（以 2026-11-06 截止为约束）
P0：中文默认与国际化核查；地图/展馆/三游戏基础通路；移除明显混语；移动端读写/操作；真实展示视频。
P1：展品卡片的来源与中俄文化对照；导航一致；图片不裁切与资源本地化。
P2：角色表情统一、低成本对话框与动效；精细模型与复杂新系统暂不应干扰 P0。

## 实施原则
每个改动必须从工作代码、实际截图和可复现的手机/桌面浏览器测试中验证，避免将概念图视作真实成品；在截止前不做大规模高风险重构。
