# Локальные 3D-модели и авторство

## Верблюд (локальный GLB)

- Файл: `assets/models/camel-poly-pizza.glb`
- Источник копии: [billcookie/Pax-Atlas](https://github.com/billcookie/Pax-Atlas/blob/main/src/assets/models/camel.glb)
- Оригинальный автор модели: **jeremy** (Poly Pizza), согласно README проекта Pax Atlas
- Лицензия: **CC BY 3.0** (необходимо указывать автора)
- В музее: Three.js `GLTFLoader` загружает файл напрямую с нашего сайта. При ошибке остаётся исходная процедурная модель.
- Внимание: геометрия импортированного верблюда пока **не подтверждена как двугорбый бактриан**. Перед публичной конкурсной демонстрацией необходимо проверить число горбов и пропорции. При несоответствии заменить на проверенного бактриана.

## Модель LynxAbraxas

- [Camel, Sketchfab](https://sketchfab.com/3d-models/camel-794fd9fe9d224bb9ba8ddae8a499321e), LynxAbraxas, CC BY.
- Источник Blender-проекта автора: [LynxAbraxas/sprites/camel.blend](https://github.com/LynxAbraxas/sprites/blob/master/camel.blend).
- Эта модель **ещё не внедрена**. Файл Sketchfab скачивается через авторизованный Download API, а открытый `.blend` надо отдельно экспортировать в GLB/GLTF.

## Самовар Nikolay Fedorov

- [Samovar, Sketchfab](https://sketchfab.com/3d-models/samovar-83499690f2c243b2ab67458bc1eb8955), Nikolay Fedorov, CC BY.
- В текущей сборке остаётся **собственная процедурная реконструкция самовара**. Оригинальный файл из Sketchfab ещё не получен — официальный Download API требует входа в Sketchfab.
- После получения официально скачанного glTF ZIP можно встроить реальный PBR-объект, оптимизировать для смартфонов и сохранить данное авторство.

## Для конкурса
Авторство CC BY должно быть видно пользователю, не только в исходном коде. Проверять реальное происхождение модели, лицензию, историю модификаций и фактический вид перед публичным распространением.
